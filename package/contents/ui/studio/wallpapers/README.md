# Studio wallpapers

Canonical preview assets for the QML settings studio and HTML demo.

- `pine-lake.png`: unchanged copy of `assets/wallpapers/desktop.png` from the local
  `/mnt/projects/nixos-config` setup, selected at the owner's request.
- `afterglow.png`: unchanged copy of that setup's `assets/wallpapers/lockscreen.png`.
- `midnight-marina.svg`: original vector scene inspired by
  [Muddyblack's Midnight Marina](https://marketplace.visualstudio.com/items?itemName=Muddyblack.midnight-marina):
  midnight seas, teal, electric blue, aqua reflections and distant marina lights.
- `aurora-sound.svg`, `moss-mist.svg`, `silver-tide.svg`: original vector scenes
  extending that palette into aurora, forest and light daytime alternatives.

Names, stable IDs, filenames and fallback colours live in `../StudioCatalog.js`.
Run `python3 tools/sync_studio_assets.py` from the repository root after changes.
The files under `docs/website/assets/studio` are ignored build outputs, generated by
`make docs` locally and by the Pages workflow. Only these originals are tracked.
These are preview backdrops, not changes to the user's desktop wallpaper.
